Can Claude Code Read Images?

October 28, 2026 · ClaudHQ

Updated October 28, 2026. Yes. Claude Code reads PNG, JPEG, GIF, and WebP files and returns them to the model as visual content, not raw bytes. Drag or paste an image into the session, or give Claude the file path. Images larger than 128 MB are refused, and large screenshots may be downscaled.

People ask whether Claude Code can look at screenshots, mockups, and diagrams. It can. The Read tool treats image files as visual content that the model can see, so you can ask questions about a screenshot instead of describing it in words.

Supported image formats

The Read tool accepts four image formats:

  • PNG
  • JPEG
  • GIF
  • WebP

Other image formats and binary files are refused. If Claude cannot read a file, it receives the path but not the contents. A refusal message usually suggests a shell command or script that can convert the file.

How to give Claude an image

There are three practical ways to add an image to a session:

  • File path: mention the image with @ or give the path in your prompt, such as @screenshots/checkout-error.png.
  • Drag and drop: drag an image file into the Claude Code window.
  • Paste: copy an image and paste it into the session.

Then ask a direct question: What error is shown in this screenshot? or Does this mockup match the layout in our CSS? You can include several images in one conversation, which helps when you compare a design against an implementation.

Size limits and downscaling

Claude Code resizes and recompresses large images before sending them to the model. On a big screenshot, Claude may see a downscaled copy and miss fine pixel-level detail. The Read tool refuses any image file larger than 128 MB and tells Claude to resize the image or export a smaller copy.

If detail matters, crop the region you care about first. For example, use ImageMagick from Bash to cut the exact area, then read the crop. A smaller crop keeps the pixels you need and stays under the size limit.

What image analysis is good for

  • Error screenshots: read a stack trace or dialog text and propose a fix.
  • UI review: compare a design mockup with the current page and list spacing or color gaps.
  • Diagrams: explain an architecture drawing or a database schema.
  • Charts: summarize a graph and point out outliers.

Image analysis is not OCR for every document, and it does not replace a real browser test. Treat the answer as a second pair of eyes, then confirm the result in code or in the browser.

For PDF documents, use the PDF page-range guide instead. For install and shell setup, see Claude Code on Windows.
