MCP Configuration Help

File Structure

MCP configs are JSON files with a "mcpServers" object containing server definitions.

Required Fields

command: Full path to the server executable

args: Array of command-line arguments

Optional Fields

env: Environment variables for the server

transport: "stdio" (default) or "sse"

Common Paths

Linux/Mac: ~/.config/claude/claude.config.json

Windows: %APPDATA%/Claude/claude.config.json
