Best Practices for claude.md

  • Start with a clear title/context section
  • Use hierarchical headings (# for main, ## for sections)
  • Keep rules concise and actionable
  • Use code blocks for examples (```)
  • Avoid conflicting instructions in different sections
  • Include escape sequences for special characters
  • Don't duplicate rules across sections
  • Provide context for "why" not just "what"
